This folder is for any images or files you add later.

The interface ships with no image downloads at all: every icon and
product visual is inline SVG generated by Icons.java or written
directly into the HTML. That keeps the app fast and lets it run with
no internet connection during your review.

Anything you drop in here is copied to the deployed app by deploy.bat
and can be used as, for example:  <img src="assets/my-photo.jpg" alt="...">
